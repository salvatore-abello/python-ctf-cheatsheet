## Reverse Engineering

## Python Bytecode

 - Bytecode decompiler (Python <= 3.8): uncompyle6 [A cross-version Python bytecode decompiler](https://github.com/rocky/python-uncompyle6)
 - Bytecode & marshal blobs decompiler (Python <= 3.11): [C++ python bytecode disassembler and decompiler](https://github.com/zrax/pycdc)
 - Bytecode decompiler: pylingual https://pylingual.io
 - Marshal blob to pyc converter: marshal2pyc https://github.com/salvatore-abello/marshal2pyc
 - Bytecode disassembler: dis https://docs.python.org/3/library/dis.html

## Pickle bytecode
 - Pickle disassembler: pickletools https://docs.python.org/3/library/pickletools.html
 - Pickle decompiler: fickling [A Python pickling decompiler and static analyzer](https://github.com/trailofbits/fickling)
 - Pickle debugger: pickledbg [A GDB+GEF-style debugger for unloading Python pickles](https://github.com/Legoclones/pickledbg)
 - Pickle debugger: BetterPickleDbg [pickledbg with steroids](https://github.com/salvatore-abello/BetterPickledbg)
